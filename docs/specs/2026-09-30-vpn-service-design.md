# VPN-сервис — дизайн (2026-09-30)

## Цель
Свой VPN для меня и семьи/друзей (~до 20 человек), подключение из России, клиент — Happ
через subscription URL. Уведомления о сбоях, скорости и задержках в Telegram,
перезапуск VPN из бота. Весь код в git, деплой одной командой без пароля.

## Решения
- **Протокол:** VLESS + Reality + XTLS-Vision (Xray-core) на 443/tcp. WireGuard/OpenVPN
  из РФ блокируются DPI, Reality маскируется под TLS к крупному сайту.
- **Стек:** чистый Xray + свой бот (без веб-панелей: меньше поверхность атаки, всё в git).
- **Подписка Happ:** Caddy на 8443, домен `<IP>.sslip.io`, сертификат Let's Encrypt.
  Ответ — base64 списка `vless://` + заголовки `profile-title`, `subscription-userinfo`,
  `profile-update-interval`, `support-url`.
- **Сервер:** существующий Hetzner (hel1). **На нём уже работает другой бот** — изоляция:
  отдельная директория `/opt/vpn-service`, свой docker compose project, не трогаем его
  порты/процессы, firewall-правила добавляем только после инвентаризации.
- **Бот:** Python 3.12 + aiogram 3, в Docker. Админ-функции (статус, метрики, speedtest,
  рестарт Xray / сервера с подтверждением, выдача/отзыв ключей с QR). Алерты с
  антиспамом (дедуп + «восстановлено»), авто-рестарт Xray при падении.
- **Внешний сторож:** GitHub Actions cron */5: TCP-проверка 443 и 8443 снаружи,
  алерт в Telegram, опциональный hard reboot через Hetzner API.
- **Доступ:** SSH только по ключу (`.secrets/`), пользователь `deploy`, project-local
  `ssh_config`, `make deploy`. GitHub — deploy key с правом записи только в этот репо.
- **Секреты:** `.env` на сервере и локально, в git — только `.env.example`.

## Риски
- Подсети Hetzner частично ограничиваются в РФ → проверить с домашнего и мобильного
  интернета сразу после деплоя; архитектура допускает вторую ноду у другого хостера.
- Общий сервер с существующим ботом → конфликт портов/ресурсов; решается инвентаризацией.

## Тестирование
pytest: генерация конфигов Xray, ссылок `vless://`, подписки, логика алертов.
Перед деплоем — `xray run -test`. E2E: подключение Happ, алерт при остановке Xray.

## Уточнения после инвентаризации (2026-10-01)
- Сервер: Ubuntu 26.04, 2 vCPU / 3.7 GB, `funnel-bot` в Docker (polling, без входящих портов) —
  конфликтов по портам нет.
- SSH: деплой под root по ключу `.secrets/vpn_ed25519`. **Вход по паролю оставлен** по решению
  владельца; защита — fail2ban.
- Reality в режиме *self-steal*: SNI = `46-62-140-16.sslip.io`, dest = локальный Caddy с
  настоящим сертификатом. Подписка Happ отдаётся через тот же 443
  (`https://46-62-140-16.sslip.io/sub/<token>`), отдельный внешний порт 8443 не нужен.
- Ребут сервера — через Hetzner Cloud API (работает и когда сервер завис).
